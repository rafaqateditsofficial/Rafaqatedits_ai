RAFAQAT.AI update from your Android phone (GitHub only)

1. Unzip this file on your phone. Keep the folder structure.
2. Open github.com in Chrome (Desktop site on), open your repository.
3. Tap Add file > Upload files. Choose ALL files and folders from the unzip, then Commit changes.
   If folders will not upload, open each folder in GitHub and upload its files there (assets/css, assets/js, assets/img, config, i18n, pages, docs).
4. The old files (index.html, style.css, logo.svg, favicon.svg) can stay. Only index.html is replaced.
5. Wait 1-2 minutes, open your GitHub Pages link and refresh.
6. Test each menu item. Then open Integrations to connect a text AI provider.
